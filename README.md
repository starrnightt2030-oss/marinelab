# ورشة المواسير الافتراضية — MarineLab 3D
مركز تدريب شركة ترسانة الإسكندرية · تخصص برادة وتركيبات خطوط المواسير

تم تصميم وتطوير التطبيق بواسطة Mohamed-Eldawly

## الرفع على GitHub Pages
1. اعمل Repository جديد على GitHub (مثلاً `marinelab`).
2. ارفع كل محتويات الفولدر ده (index.html والفولدرات اللي جنبه) في جذر الـ Repository.
3. من Settings ← Pages اختار Branch: `main` وفولدر `/ (root)` واضغط Save.
4. بعد دقيقة أو اتنين التطبيق هيشتغل على: `https://<اسم-الحساب>.github.io/marinelab/`

## التثبيت
- **الموبايل (أندرويد / كروم):** افتح الرابط ← قائمة النقط التلاتة ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون (سفاري):** زرار المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **الشاشة التفاعلية 75 بوصة (ويندوز):** افتح الرابط في Microsoft Edge ← أيقونة «تثبيت التطبيق» في شريط العنوان. هيفتح ملء الشاشة ويشتغل باللمس.
- بعد أول فتح التطبيق بيشتغل **من غير إنترنت**.

## الشرح الصوتي
الشرح بيستخدم صوت العربي المتسطب في الجهاز. على ويندوز: Settings ← Time & Language ← Speech ← Add voices ← Arabic (Egypt).
لو مفيش صوت عربي، الشرح بيظهر مكتوب على الشاشة.

## ملاحظة
الأبعاد في التمرين أبعاد تدريبية توضيحية لخط DN100، وليست بديلاً عن الرسومات الهندسية المعتمدة أو عن التدريب العملي في الورشة.
